Jumping Glass

How to play

  • Press Enter to start the game
  • Press Space to jump
  • Press Arrow Down to crouch (dodge airplanes)
  • Avoid all obstacles or the glass will break!

How to run

Open index.html in any web browser.

Files

  • index.html - the main HTML file
  • style.css - styling and layout
  • game.js - all the game logic
  • pictures/ - all game images
  • sounds/ - all game audio
